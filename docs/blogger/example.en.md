# Example Post

> This is a sample of how to write a post. Follow this format for your own posts.

## Writing Format at a Glance

Posts are written in **Markdown**. It's simple — just remember a few rules below.

### 1. Headings

Put `#` in front of text to make a heading. More `#` means a smaller heading.

- `# Level 1 Heading` (usually only once per post)
- `## Level 2 Heading`
- `### Level 3 Heading`

### 2. Bold and Italic

- **Bold**: `**bold text**`
- *Italic*: `*italic text*`

### 3. Lists

Unordered lists start with `- `:

- Item one
- Item two

Ordered lists start with `1. `:

1. First step
2. Second step

### 4. Code

Inline code is wrapped in backticks: `print("hello")`

Code blocks use triple backticks:

```python
print("this is a code block")
print("great for code examples")
```

### 5. Admonitions (pretty colored boxes)

```admonition note
This is a blue "note" box
```

```admonition tip
This is a green "tip" box
```

!!! warning "Attention"
    This is a yellow "warning" box

### 6. Images

```markdown
![Alt text](image URL)
```

### 7. Links

```markdown
[Link text](link URL)
```
