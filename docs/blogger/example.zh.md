# 文章示例

> 这篇是"怎么写文章"的示例，以后你按这个格式写就可以了。

## 文章格式速览

写文章用的是 **Markdown 语法**，很简单，记住下面几个就够了。

### 1. 标题

在文字前面加 `#` 就是标题。`#` 越多，标题越小。

- `# 一级标题`（一般一篇文章只用一次）
- `## 二级标题`
- `### 三级标题`

### 2. 加粗和斜体

- **加粗**：`**加粗文字**`
- *斜体*：`*斜体文字*`

### 3. 列表

无序列表用 `- ` 开头：

- 第一条
- 第二条

有序列表用 `1. ` 开头：

1. 第一步
2. 第二步

### 4. 代码

行内代码用反引号包起来：`print("你好")`

多行代码用三个反引号：

```python
print("这是多行代码")
print("适合贴代码示例")
```

### 5. 提示框（漂亮的彩色小方块）

```admonition note
这是蓝色"笔记"提示框
```

```admonition tip
这是绿色"小贴士"提示框
```

!!! warning "注意"
    这是黄色"警告"提示框

### 6. 图片

```markdown
![图片说明](图片地址)
```

### 7. 链接

```markdown
[链接文字](链接地址)
```
